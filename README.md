# Z-Image particle sliders

Explicit LR controls and qualification scope: [LEARNING-RATES.md](LEARNING-RATES.md).

This is the canonical repository for the opt-in Z-Image shared-game CPU preview.
The active distribution is `embedded-zimage-shared-preview` version `0.1.4`, with
import namespace `embedded_zimage_shared` and cohort
`embedded-zimage-adapter-gan-pg094-hg-hndl010-v5`.

The active candidate pins shared core
`ddb41423bcefc1fe76cd94d0f9b367353b3ea137`, including the merged shared
plan and isolated execution APIs. This does not qualify a
pretrained Z-Image model, GPU training, production resources, image quality or
new response domains. This product is tested with tiny random native models on
CPU only. Claude RETURN review remains required before landing this draft.

## Separate installation

Use a fresh Python environment. The current tested runtime is Python 3.11.17 with
PyTorch 2.15.0+cpu. For Linux x86_64 and Python 3.11:

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install --index-url https://download.pytorch.org/whl/cpu 'torch==2.15.0+cpu'
.venv/bin/python -m pip install '.[test]'
.venv/bin/python -m pip check
```

The exact Git dependency and subdirectory are declared in `pyproject.toml`.
Its `hypergan-hndl` extra selects official ParticleGAN 0.9.4, HyperGAN develop
`5f368a3770cf5bdae0448995c9f76e29af8049f7` and HNDL 0.10.0. Do not co-install the
legacy HNDL extra. The recursive lock covers every installed core source/data
file except generated bytecode, including the core license. Installed origin,
source bytes and builder closure are verified before native attachment.

## Native response contract

This is an ordinary rank-16/alpha-16 attention adapter GAN. It has no routed
particle bank. The existing Q/K/V/output LoRA computation executes through a
verified HyperGAN/HNDL graph. The shared `ImageResponseAdapter('zimage')`,
`HNDLFieldCritic`, `ConditionalPG094`, response session and inference session own
native forwarding and the training lifecycle. No GAN loss or optimizer is copied.

The frozen positive-caption response is the target; the student uses the neutral
caption. Native guidance 0 maps to shared guidance 1, meaning direct conditional
velocity. Native list inputs, `(1000-t)/1000`, output negation and the full
`[1,C,H,W]` field are preserved. No vector flattening or domain-guard bypass occurs.
This shared adversarial objective remains separate from the historical UNI MSE
trainer, which is tracked for later migration and remains untouched upstream.

Only explicitly staged, finite FP32 CPU native model bundles are accepted. No
weights are downloaded. Provide `config.json` and unsharded
`diffusion_pytorch_model.safetensors`, plus frozen pre-encoded rows:

```python
from embedded_zimage_shared.backend import bundle_identity, PROTOCOL
packet = dict(schema=PROTOCOL, model_identity=bundle_identity(model_dir), rows=[
    dict(neutral={"embeds": neutral}, positive={"embeds": positive},
         negative={"embeds": unconditional}, latent=z, timestep=t),
    # At least two rows. z=[1,C,H,W], embeds=[tokens,cap_feat_dim], t=raw scalar.
])
torch.save(packet, rows_path)
```

The CLI binds the complete rows-file SHA256. Model file hashes and the native
state digest use bounded reads without loading a second copy of the base.
Scoped initialization uses the declared seed for adapters, seed + 1 for the critic,
seed + 2 for native loading and seed + 3 for preparation. CPU RNG is restored on
success and failure. This profile does not discover or initialize CUDA devices.

```sh
embedded-zimage-shared train --model-dir LOCAL_MODEL --rows frozen-rows.pt \
  --shape 1 4 4 4 --steps 4 --stop-after 2 \
  --checkpoint modern-resume.pt --export modern-raw.pt
embedded-zimage-shared response --model-dir LOCAL_MODEL --artifact modern-raw.pt \
  --request native-request.pt --strength 0.5 --output native-velocity.pt
```

The dimensions above are a tiny-fixture example, not a production model card.
Native requests contain only `condition={"embeds": tensor}`, `latent` and
`timestep`. Strength 0 is the frozen base. Raw and EMA exports support numerical
inference without training rows, critics or optimizers.

## Artifact and review boundaries

New training uses the selected upstream ParticleGAN recipe with raw exports and
no host EMA by default. `--ema-decay` and `--selection ema` are an explicit
nondefault experiment; selecting EMA without its decay is rejected before loading.

Version 0.1.2/cohort v3 remains bound to core `7a8a321d04323d49319d0b08e6093a0ddce36b27`
and its original source pin. Version 0.1.4/cohort v5 uses a new exact core/source identity and refuses
previous-cohort packets. Version 0.1.3/cohort v4 retains its original
`a794e3b4a8813b012f2c4faa3da82b78d4a90214` pin and archived evidence
in `docs/cohort-v4/`. No old packet is rewritten or
relabeled. The native response/row protocol remains version 2; caches whose model
identity binds the old core must be regenerated explicitly for the new cohort.

Training resume binds exact configuration, paths, source/runtime and step budget.
Native-only exports may use relocated byte-identical base files in the same pinned
runtime. They do not imply cross-cohort or cross-runtime portability. Transient
native cleanup failures remain visible and can be retried; operation errors keep
priority over cleanup failures. Deep same-config training-signature admission
still follows reversible preparation in the shared core. Universal pre-hook
packet refusal is not claimed.

`CORE-MIGRATION.md` and `docs/pg094-upgrade.md` record the current pin,
complete 574-file source closure, installed dispatcher and test boundary.
`EXTRACTION.md` and `provenance.json` retain the source-export history.
`docs/source/` contains immutable archival evidence with its original formatting;
it is not the current installation guide. The LoRA module reference matches the
historical numerical module, while shared-network discovery differs. Tests cover
bounded native target names and numerical parity, not full historical discovery.

No workflows, permission changes, releases, deployments, model weights, GPU jobs
or merges are included in this draft.
