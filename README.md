## Native response contract

This is an ordinary rank-16/alpha-16 attention adapter GAN. It has no routed
particle bank. The existing Q/K/V/output LoRA computation executes through a
verified HyperGAN/HNDL graph. The shared `ImageResponseAdapter('zimage')`,
`HNDLFieldCritic`, `ConditionalParticleGAN`, response session and inference session own
native forwarding and the training lifecycle. No GAN loss or optimizer is copied.

The frozen positive-caption response is the target; the student uses the neutral
caption. Native guidance 0 maps to shared guidance 1, meaning direct conditional
velocity. Native list inputs, `(1000-t)/1000`, output negation and the full
`[1,C,H,W]` field are preserved. No vector flattening or domain-guard bypass occurs.
This shared adversarial objective remains separate from the historical UNI MSE
trainer, which is tracked for later migration and remains untouched upstream.

Only explicitly staged, finite FP32 CPU native model bundles are accepted. No
weights are downloaded. Provide `config.json` and unsharded
`diffusion_pytorch_model.safetensors`, plus frozen pre-encoded rows:

```python
from embedded_zimage_shared.backend import bundle_identity, PROTOCOL
packet = dict(schema=PROTOCOL, model_identity=bundle_identity(model_dir), rows=[
    dict(neutral={"embeds": neutral}, positive={"embeds": positive},
         negative={"embeds": unconditional}, latent=z, timestep=t),
    # At least two rows. z=[1,C,H,W], embeds=[tokens,cap_feat_dim], t=raw scalar.
])
torch.save(packet, rows_path)
```

The CLI binds the complete rows-file SHA256. Model file hashes and the native
state digest use bounded reads without loading a second copy of the base.
Scoped initialization uses the declared seed for adapters, seed + 1 for the critic,
seed + 2 for native loading and seed + 3 for preparation. CPU RNG is restored on
success and failure. This profile does not discover or initialize CUDA devices.

```sh
embedded-zimage-shared train --model-dir LOCAL_MODEL --rows frozen-rows.pt \
  --shape 1 4 4 4 --steps 4 --stop-after 2 \
  --checkpoint modern-resume.pt --export modern-raw.pt
embedded-zimage-shared response --model-dir LOCAL_MODEL --artifact modern-raw.pt \
  --request native-request.pt --strength 0.5 --output native-velocity.pt
```

The dimensions above are a tiny-fixture example, not a production model card.
Native requests contain only `condition={"embeds": tensor}`, `latent` and
`timestep`. Strength 0 is the frozen base. RAW exports support numerical
inference without training rows, critics or optimizers.

## Scheduled strength on an owned native pipeline

Call `embedded_zimage_shared.scheduled_render.render(pipeline,
scale_adapter=network.scaled, step_gains=gains, num_inference_steps=len(gains),
**inputs)` with the staged ZImage pipeline and its attached RAW adapter.
The output uses the pipeline's normal latent or image return path.
The trace records native timesteps and effective strengths. With the same
unit gains at every step, this applies the nominal strength throughout.

Early-heavy strength improved all four matched cases of the archived
Golden Hour RAW64 profile. Its mean finished-image gain was +0.00555,
compared with +0.00347 constant and +0.00117 late-heavy at nominal 0.5.
The original 512-pixel BF16 CUDA CFG0 path used nine native Euler steps
and its pinned FP32 VAE. All twelve images passed independent integrity.

### Activation-gated strength

Supply a fitted `LatentGatePlan` to the same renderer for a single native
image trajectory. The gate reads the FP32 mean of each latent channel across
the frame and spatial axes just before the transformer call. With CFG, it
reads the conditional latent and retains the native joint forward and the
same adapter strength on both copies. A fired gate applies the nominal
strength for that Euler interval. The trace records each decision, the actual
sigma grid, and `sigma_weighted_strength`, the sum of effective strengths
weighted by their native interval widths.

```python
from embedded_zimage_shared.activation_gate import LatentGatePlan
from embedded_zimage_shared.scheduled_render import render

plan = LatentGatePlan(
    core_wheel=verified_shared_core_wheel,
    method="cfp",
    direction=fitted_unit_direction,
    parameter=fitted_threshold,
    calibration_sha256=frozen_calibration_record_sha256,
)
output, trace = render(
    pipeline,
    scale_adapter=network.scaled,
    gate_plan=plan,
    strength=matched_nominal_strength,
    num_inference_steps=native_step_count,
    **inputs,
)
```

Use `method="clabs"` with the fitted bias as `parameter`, a recorded `seed`,
and the measured `CLABSParameters` fields in `clabs`. The matched random
control takes a measured budget rate and seed as its `parameter` and `seed`,
with no direction. For exact strength replay, use the same starting latent,
conditioning and sampler with fixed gains derived from the traced
`effective_strengths` divided by the nominal strength. The strict RAW loader,
fixed-strength path, and existing fixed schedules keep their original
dependencies and source identity. Build the companion wheel at the full
shared revision in [core #269](https://github.com/HyperGAN/particle-sliders/pull/269)
and pass its path to `core_wheel`. The renderer verifies and loads just its
standalone steering module. [Shared equations and calibration protocol](https://github.com/HyperGAN/particle-sliders/blob/b1f780decc516808cfd3019d5e5b674457161f86/docs/strength-schedules.md#activation-dependent-steering)

Fit the direction on paired target and neutral pre-edit latent trajectories.
Choose the threshold or bias on separate active calibration renders at the
declared firing budget. On each held-out prompt and seed, divide the gate's
actual sigma-weighted strength by the total native interval width to obtain
that case's dose-matched constant. Compare the gate, constant and random
control under the same checkpoint, seed, Euler grid and OFF reference.

The Golden Hour RAW64 study used the original 512-pixel BF16 CUDA CFG0
runtime, nine Euler intervals and pinned FP32 VAE. At the 50% calibration
target, CFP fired on 19 of 36 intervals and CLABS on 17 of 36. On four
held-out cases, CFP improved mean Golden Hour intensity by +0.00361 over OFF
and +0.00232 over its same-dose constant. CLABS measured +0.00390 over OFF
and +0.00234 over its same-dose constant. Each gate had two wins and two ties
against its control. All 24 gate and control images passed independent
integrity checks. The archived early-heavy fixed schedule had mean gain
+0.00555 over OFF on the same cases and remains the measured preset.
[Per-case adaptive results](docs/golden-hour-raw64-adaptive-strength.json).
